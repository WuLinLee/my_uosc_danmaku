## uosc_danmaku 弹幕增强扩展 2026.10.12

## 安装位置

将 [WuLinLee/my_uosc_danmaku](https://github.com/WuLinLee/my_uosc_danmaku) 中的 `portable_config` 文件夹解压并覆盖到：
E:\mpv-lazy\mpv-lazy\\

保留目录结构；不要把 portable_config 再解压进另一个 portable_config 目录。
这次更新涉及 4 个弹幕脚本模块和 2 个弹幕配置文件，另有 1 个 uosc 控制栏配置文件。`mpv.conf`、`input_uosc.conf`、字体、快捷键及其他脚本均未改动：

- portable_config/scripts/uosc_danmaku/modules/menu.lua
- portable_config/scripts/uosc_danmaku/modules/parse.lua
- portable_config/scripts/uosc_danmaku/modules/options.lua
- portable_config/scripts/uosc_danmaku/modules/style.lua
- portable_config/script-opts/uosc_danmaku.conf
- portable_config/script-opts/uosc.conf（新增：仅控制 uosc 控制栏排列）

## 菜单入口
重启 mpv 后打开原有「弹幕设置」总菜单，进入「弹幕样式」。样式与过滤参数现在集中在同一个菜单里：

1. 智能弹幕密度：默认 `50`，范围 0–100。100 不进行智能密度筛选；数值越低，在局部弹幕拥挤时筛选越积极。
2. 弹幕行间距：1.0–2.0 倍字号，默认 1.2；数值越高，轨道之间留出的垂直间隔越大。
3. 均匀分布弹幕轨道：默认开启。排版先检查碰撞，再优先使用未使用过且靠近画面中心的轨道，随后复用最久未使用的可用轨道，避免旧版 first-fit 总是从上到下堆叠。
4. 重复弹幕合并间隔：默认 `0`，范围 -1 到 30 秒。-1 表示关闭合并；0 只合并时间相同的重复内容；正数按该秒数合并重复内容。
5. 同屏弹幕上限：0–500。0 表示不限；大于 0 时沿用原有的同屏数量限制算法。
6. 跨颜色/类型合并重复弹幕：开启后，同一内容即使类型或颜色不同也可进入同一重复合并组。
7. 屏蔽词过滤：启用或暂停屏蔽词规则。
8. 管理屏蔽词规则：在菜单顶部搜索栏输入规则并回车添加；每条规则右侧的删除动作可移除该规则。
9. 菜单底部统一使用「保存当前样式和过滤设置」或「清除已保存样式和过滤设置」。
   - 清除会删除跨进程 JSON，并立即把本次运行中的样式/过滤项恢复为读取 `.conf` 后的基准值、刷新当前弹幕与帧率滤镜，同时更新菜单里的单项重置基准。

样式与过滤参数的代码默认值集中在 `options.lua` 的 `DANMAKU_STYLE_DEFAULTS` 表里，`.conf` 不再重复声明这些默认值。`uosc_danmaku_style.json` 是菜单保存后生成的用户状态文件，不再随仓库分发，避免更新时覆盖个人保存的设置；已有本地 JSON 请在更新时保留。启动时，JSON 中存在的有效样式值会覆盖 `.conf` 和代码默认值；点击「清除已保存样式和过滤设置」会删除该 JSON，并把当前运行恢复为读取 `.conf`（以及命令行选项）后的基础值。默认字体为 `Source Han Sans`、字号为 `55`、透明度为 `0.70`、显示范围为 `0.8`。所有菜单样式和过滤设置仍共用同一份运行时 JSON；粗体保留原有的 `false` / `true` 两档。


## 布局说明
- `displayarea=0.05` 表示弹幕只使用画面高度的 5%。代码默认值为 `0.8`；如果用户手动在 `.conf` 中设置该字段，则以 `.conf` 为清除 JSON 后的基础值；如果 JSON 存在有效值，启动时仍优先采用 JSON。该值同时用于弹幕布局和智能密度计算。想让弹幕覆盖整个画面，可设为 `1.0` 后使用底部按钮保存。
- 旧版滚动弹幕布局采用从上到下的 first-fit 轨道选择：只要顶部某行能够放下，就不会主动选择其他空行，因此可用区域很大时也可能看起来偏上。新版的“均匀分布弹幕轨道”会在碰撞检查后进行平衡选择。
- “弹幕行间距”只控制轨道垂直间隔，不改变字幕字号；默认 `1.2` 约在每行字号基础上增加 20% 的轨道高度。行间距越大，可用轨道数量越少，密度过高时仍可能有弹幕因无安全轨道而不显示。

## 黑名单兼容
旧配置中的 `blacklist_path` 规则文件仍会读取，也不会被菜单里的规则管理覆盖。菜单新增的规则单独保存在：
~~/script-opts/uosc_danmaku_blacklist.txt

文件每行一条规则。它使用插件原有的 Lua pattern 匹配规则，而不是 PCRE 正则表达式；普通词语可直接输入。菜单添加/删除规则后会重载规则并重新生成弹幕。新增的「屏蔽词过滤」开关会整体启用或暂停这两类规则。

已有的「从源添加弹幕」菜单仍负责屏蔽或解除屏蔽整条弹幕源。这与按文字匹配的屏蔽词不是同一个功能。

## 关于“折叠”
插件目前支持的是“重复弹幕合并”：相同文字的弹幕在符合类型、颜色和时间间隔条件时会被合并，并可能显示 xN 计数。任意相似评论自动折叠、白名单优先，以及评论组展开/收起目前都未实现。

## 保留与兼容说明
- 样式/过滤代码默认值只在 `options.lua` 的 `DANMAKU_STYLE_DEFAULTS` 中维护；`style.lua` 保存时的兼容回退也读取同一张表。`.conf` 不重复列默认值，但仍允许用户显式添加键来覆盖代码默认值。菜单保存的 JSON 是独立的运行时用户状态；它不随仓库分发，以免被项目更新覆盖。清除 JSON 后会回到读取 `.conf`/命令行选项后的基础值；未显式覆盖的项目回到 `DANMAKU_STYLE_DEFAULTS`。默认字号为 `55`、透明度为 `0.70`、显示范围为 `0.8`、智能弹幕密度为 `50`。
- `保存当前样式和过滤设置` 会把字体、粗体、样式、密度、行间距、均匀轨道开关、重复合并、同屏上限、跨样式合并、屏蔽词开关和直播帧率统一写入 `~~/script-opts/uosc_danmaku_style.json`；该文件是用户状态，不属于仓库默认配置。启动时若文件存在且包含有效值，会覆盖 `.conf`/代码中的对应样式值。保存失败时，菜单会显示具体字段或文件路径错误。
- 当同屏上限大于 0、合并间隔小于或等于 0 时，排版阶段仍按原有逻辑使用滚动时长作为实际合并窗口；菜单里显示的合并间隔不会因此被改写。
- 智能密度算法是对浏览器版思路的 LuaJIT 兼容适配，不是完整 Unicode NFKC 的逐字节等价移植。

## 控制栏快捷按钮
新增 `portable_config/script-opts/uosc.conf`，将 `button:danmaku_menu` 放在 `<has_chapter>chapters` 后面。uosc 会显示一个图标按钮，悬停提示为「弹幕设置」；点击后打开插件原有的「弹幕设置」总菜单，进入「弹幕样式」即可统一调整样式和过滤设置。按钮使用 uosc 官方的 `set-button` + `button:<name>` 扩展方式；插件中已有 `danmaku_menu` 注册，无需新增独立 Lua 脚本。

没有改动 `portable_config/script-opts.conf`，以免覆盖其中的其他脚本配置。`portable_config/script-opts/uosc.conf` 是 uosc 单独使用的配置文件；如果本机已经有同名 `uosc.conf`，先备份，再把这里的 `controls=` 行合并进去。
